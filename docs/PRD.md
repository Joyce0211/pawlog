# PawLog 宠物健康日记 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
**PawLog 宠物健康日记** 是一款专为养宠人设计的健康管理工具，帮助宠物主人系统化记录爱宠的健康状况、日常护理和支出管理。

### 1.2 核心价值
- **健康追踪**：记录体重、疫苗、驱虫、刷牙、医疗等健康数据
- **智能提醒**：基于记录自动生成下次提醒，避免遗漏重要事项
- **科学记账**：记录养宠支出，分析消费结构，合理规划预算
- **历史检索**：支持按类型、关键词、日期多维度检索历史信息

### 1.3 目标用户
- 注重科学养宠的精细化宠主
- 多宠物家庭
- 需要管理宠物医疗/饮食支出的用户
- 新手宠物主人

## 2. 用户画像与核心场景

### 2.1 典型用户画像
| 属性 | 描述 |
|------|------|
| 年龄 | 25-45岁 |
| 身份 | 城市白领，视宠物为家庭成员 |
| 痛点 | 记不住驱虫/疫苗时间、宠物生病时无法提供完整病史、养宠开支不清晰 |
| 需求 | 简便的记录方式、智能提醒、支出统计 |

### 2.2 核心业务场景

**场景一：突发就医**
- 情境：狗狗突然呕吐，医生询问上次驱虫时间和体重变化
- 行动：打开App，通过筛选功能快速找到驱虫记录和体重曲线
- 结果：30秒内提供准确信息辅助诊断

**场景二：日常护理打卡**
- 情境：晚上遛狗回来，给狗狗擦脚、刷牙
- 行动：打开App，进入"刷牙日历"页面，点击当天日期记录
- 结果：极简操作完成记录，日历自动标亮

**场景三：周期提醒**
- 情境：该打疫苗了，但用户忘记了
- 行动：App根据上次记录的"有效期"，提前推送通知
- 结果：避免疫苗脱保

**场景四：月底对账**
- 情境：月底想了解本月养宠开支
- 行动：进入"账本"页面，查看本月支出统计
- 结果：清晰了解钱花在哪里

## 4. 健康记录类型详细说明

### 4.1 体重记录 (weight)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | string | 是 | 记录日期，格式YYYY-MM-DD |
| weight | number | 是 | 体重数值，单位kg |
| note | string | 否 | 备注信息 |

### 4.2 健康记录 (health)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | string | 是 | 记录日期 |
| symptoms | string | 是 | 症状描述 |
| temp | number | 否 | 体温，单位℃ |
| doctor | string | 是 | 是否就医，yes/no |
| note | string | 否 | 备注信息 |

### 4.3 刷牙记录 (brush)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | string | 是 | 记录日期 |
| status | string | 是 | 刷牙状态，done(已完成)/skip(跳过) |
| note | string | 否 | 备注信息 |

### 4.4 驱虫记录 (deworm)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | string | 是 | 记录日期 |
| product | string | 是 | 驱虫药名称 |
| note | string | 否 | 备注信息 |

### 4.5 疫苗记录 (vaccine)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | string | 是 | 记录日期 |
| name | string | 是 | 疫苗名称 |
| clinic | string | 否 | 兽医诊所名称 |
| note | string | 否 | 备注信息 |

### 4.6 美容记录 (grooming)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | string | 是 | 记录日期 |
| type | string | 是 | 美容类型，bath(洗澡)/grooming(美容)/other(其他) |
| note | string | 否 | 备注信息 |

## 5. 信息结构

### 5.1 数据模型

**宠物 (Pet)**
```json
{
  "id": "uuid",
  "name": "旺财",
  "breed": "柴犬",
  "gender": "male|female|unknown",
  "birthday": "2020-05-20",
  "avatar": "base64或url"
}
```

**健康记录 (Log)**
```json
{
  "id": "uuid",
  "petId": "uuid",
  "type": "weight|health|brush|deworm|vaccine|grooming",
  "date": "2024-05-20T10:00:00Z",
  "data": {
    "weight": "10.5",
    "symptoms": "呕吐",
    "temp": "38.5",
    "doctor": "yes|no",
    "status": "done|skip",
    "name": "疫苗名称",
    "clinic": "诊所名称",

    "type": "bath|grooming|other"
  },
  "note": "备注信息"
```

## 7. 交互流程

### 7.1 添加健康记录流程
1. 点击右下角FAB按钮 → 弹出记录类型菜单
2. 选择记录类型 → 展开对应表单
3. 选择记录日期（默认为当天，可修改）
4. 填写记录内容 → 点击保存
5. 系统更新相关页面显示
6. 显示保存成功提示

### 7.2 刷牙记录流程（刷牙日历）
1. 进入"刷牙日历"页面
2. 点击目标日期 → 弹出刷牙记录表单
3. 日期已自动填充
4. 选择刷牙状态 → 点击保存
5. 日历立即标亮该日期
6. 显示保存成功提示

### 7.3 添加支出记录流程
1. 进入"账本"页面，点击分类快捷入口
2. 填写金额（必填）
3. 选择分类（必填，默认选中当前分类）
4. 选择日期（默认为当天）
5. 添加备注（可选）
6. 点击保存

### 7.4 编辑记录流程
1. 在时间轴/账本页面点击记录
2. 弹出编辑表单，数据已填充
3. 修改内容
4. 点击保存 → 更新记录
5. 或点击删除 → 确认后删除记录

### 7.5 删除记录流程
1. 打开记录编辑模态框
2. 点击"删除"按钮（红色）
3. 弹出确认对话框："确定要删除这条记录吗？"
4. 确认删除 → 记录移除，显示成功提示
5. 取消 → 返回编辑状态

### 7.6 卡片管理流程
1. 进入"设置"页面
2. 找到"卡片管理"模块
3. 拖拽☰图标调整卡片顺序
4. 点击开关控制卡片显示/隐藏
5. 点击"撤销"按钮恢复上一步
6. 设置自动保存

### 7.7 主题颜色切换流程
1. 进入"设置"页面
2. 找到"主题颜色"模块
3. 点击喜欢的颜色圆形按钮
4. 界面立即以平滑动画切换到新主题
5. 颜色选择自动保存

### 7.8 FAB菜单展开流程
1. 点击右下角FAB按钮
2. 菜单从底部弹出，显示6种记录类型选项
3. 点击任意选项 → 关闭菜单，打开对应表单
4. 点击空白处 → 关闭菜单

## 12. 技术实现

### 12.1 技术栈

- **前端**：原生HTML/CSS/JavaScript
- **图表库**：Chart.js
- **数据存储**：localStorage（浏览器本地存储）
- **云端同步**：Supabase
- **部署**：静态Web应用（支持Vercel、Netlify等）

### 12.2 数据持久化

所有数据保存在浏览器localStorage中，支持：
- 数据自动保存
- 页面刷新后数据不丢失
- 数据导出为JSON文件备份
- 从JSON文件导入恢复数据
- Supabase云端同步

### 12.3 性能要求

| 指标 | 要求 |
|------|------|
| 首屏加载时间 | < 2秒 |
| 页面切换响应 | < 100ms |
| 动画帧率 | 60fps |
| 本地存储限制 | < 5MB |
