# PawLog 宠物健康日记 - 产品规格说明书

## 1. 项目概览

- **项目名称**：PawLog 宠物健康日记
- **项目类型**：单页Web应用（SPA）
- **核心功能**：一款专为养宠人设计的宠物健康记录工具，可记录狗狗的体重、健康、刷牙、驱虫、疫苗、美容洗澡等关键信息，并提供智能提醒和历史检索功能
- **目标用户**：注重科学养宠的狗主人，特别是精细化养宠人群

## 2. UI/UX 规格

### 2.1 布局结构

**页面区域划分**：
- **顶部导航栏**：固定高度60px，包含应用Logo、宠物切换下拉框、搜索按钮
- **侧边栏**（桌面端）：宽度240px，包含主要导航菜单
- **主内容区**：自适应宽度，包含日记时间轴、统计图表、记录表单
- **底部导航栏**（移动端）：固定高度56px，包含四个主要入口

**响应式断点**：
- 移动端：< 768px（采用底部导航）
- 平板：768px - 1024px（侧边栏可折叠）
- 桌面端：> 1024px（固定侧边栏）

## 3. 功能规格

### 3.1 核心功能

**宠物管理**：
- 添加新宠物（名字、品种、生日、性别、体重初始值）
- 编辑宠物信息
- 删除宠物
- 切换查看不同宠物
- 支持多宠物管理

**记录类型**：
1. **体重记录**：记录体重数值（kg）、备注
2. **健康记录**：症状描述、体温、是否就医、费用
3. **刷牙记录**：口腔清洁状态、使用的牙刷/牙膏
4. **驱虫记录**：驱虫药名称、用药方式、下次提醒时间
5. **疫苗记录**：疫苗名称、注射部位、兽医诊所、下次接种时间
6. **美容洗澡**：洗澡、美容项目、费用

**提醒功能**：
- 基于记录自动创建下次提醒（如驱虫后自动创建1个月后的提醒）
- 手动创建自定义提醒
- 到期前3天预提醒
- 当天正式提醒
- 逾期未记录提醒
- 支持本地浏览器通知

**历史检索**：
- 按记录类型筛选（标签筛选器）
- 关键词搜索（搜索备注内容）
- 日历视图（查看特定日期的记录）
- 时间范围筛选（本周、本月、自定义）
- 排序（按时间正序/倒序）

**统计分析**：
- 体重变化趋势图（折线图）
- 各类型记录数量统计（柱状图）
- 最近健康状态概览

### 3.2 用户交互流程

**添加记录流程**：
1. 点击FAB按钮 → 弹出记录类型选择菜单
2. 选择记录类型 → 展开对应表单
3. 填写记录内容 → 点击保存
4. 系统自动创建相关提醒（如适用）
5. 显示保存成功提示，记录出现在时间轴顶部

**查看历史流程**：
1. 进入日记/时间轴页面
2. 可使用筛选器过滤记录类型
3. 可使用搜索框搜索关键词
4. 点击日期可查看当天所有记录
5. 点击记录卡片可查看详情或编辑

**设置提醒流程**：
1. 在记录时可设置"下次提醒时间"
2. 或在个人中心手动创建提醒
3. 系统到期发送浏览器通知
4. 点击通知跳转到记录页面

### 3.3 数据存储

- 使用 localStorage 本地存储
- 数据结构采用 JSON 格式
- 支持数据导出（JSON格式）
- 支持数据导入

### 3.4 边缘情况处理

- 空数据状态：显示友好提示和引导
- 网络断开：显示离线提示（本地存储不受影响）
- 数据验证：必填项校验、格式校验
- 删除确认：删除前显示确认对话框
- 批量操作：支持批量删除记录

## 4. 页面结构

### 4.1 页面列表

1. **首页（Dashboard）**
   - 宠物概览卡片
   - 今日待办提醒
   - 最近记录预览
   - 快速添加按钮

2. **日记（Timeline）**
   - 时间轴记录流
   - 顶部筛选器
   - 搜索栏
   - 日历视图入口

3. **统计（Stats）**
   - 体重趋势图表
   - 记录统计概览
   - 健康档案

4. **我的（Profile）**
   - 宠物档案管理
   - 提醒设置
   - 数据导出/导入
   - 关于应用

### 4.2 路由设计

- `/` - 首页
- `/timeline` - 日记时间轴
- `/stats` - 统计分析
- `/profile` - 个人中心
- `/pet/add` - 添加宠物
- `/pet/edit/:id` - 编辑宠物
- `/log/add/:type` - 添加记录
- `/log/edit/:id` - 编辑记录
